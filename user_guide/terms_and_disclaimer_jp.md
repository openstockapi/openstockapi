## 2. サードパーティデータコンプライアンス (利用規約)

データプロバイダー（証券会社、ファンドマネージャー、デジタル資産取引所を含む）は、独自の利用規約 (ToS) を適用しています。OpenStockAPI を使用する場合、これらのエンドポイントと間接的にやり取りすることになり、以下の規則を遵守する必要があります。

### 2.1 個人利用および非営利目的に限定
ほとんどの金融データプロバイダーは以下のように規定しています。
*   市場データ、財務諸表、および企業詳細は、クライアント/ユーザーの個人的かつ非営利目的の使用のみに提供されます。
*   元のデータプロバイダーの事前の書面による同意なしに、このデータを第三者にパッケージ化、商業化、または再配布することは厳しく禁止されています。

### 2.2 公正利用とレート制限 (Rate Limiting)
過剰または急速なリクエスト（スクレイピング/スパム）を行うと、サービス妨害 (DoS) 攻撃またはリソースの悪用とみなされる可能性があります。
*   **レート制限:** OpenStockAPI の組み込みのレート制限層を尊重するか、アプリケーションでカスタムのリクエストスロットリング/遅延を実装してください。
*   **キャッシュ:** API リクエストを繰り返すのではなく、静的データや履歴データ（企業プロファイルや履歴財務レポートなど）を積極的にキャッシュしてください。
*   **システムの健全性:** クールダウン期間なしで継続的な API 呼び出しを実行する無限ループを避けてください。

### 2.3 技術およびセキュリティリスク
*   **エンドポイントの安定性:** プロバイダーは、事前の通知なしに API 構造、ヘッダー、ペイロード要件を変更する権利、または着信 IP アドレスをブロックする権利を留保します。
*   **認証とセキュリティ:** 資格情報や API キーを必要とするエンドポイントの場合、構成を保護する責任はユーザー自身にあります。OpenStockAPI は、プライベートキーや資格情報を保存、送信、または監視しません（すべての操作はローカルで実行されます）。

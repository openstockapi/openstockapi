## 2. 第三方數據合規性 (服務條款)

數據提供商（包括證券商、基金管理人及數碼資產交易所）實施其各自的服務條款 (ToS)。使用 OpenStockAPI 時，您是在間接與這些接口進行交互，且必須遵守以下規則：

### 2.1 僅限個人及非商業用途
大多數金融數據提供商規定：
*   市場數據、財務報表及公司詳情僅供客戶/用戶個人及非商業用途使用。
*   未經原始數據提供商事先書面同意，嚴禁向第三方重新打包、商業化或分發此數據。

### 2.2 合理使用與頻率限制 (Rate Limiting)
發送過多或過快的請求（抓取/垃圾請求）可能被視為拒絕服務 (DoS) 攻擊或資源濫用：
*   **頻率限制:** 請尊重 OpenStockAPI 內置的頻率限制層，或在您的應用程序中實現自定義請求限制/延遲。
*   **緩存 (Caching):** 主動緩存靜態或歷史數據（例如公司簡介或歷史財務報告），而不是重複發送 API 請求。
*   **系統完整性:** 避免在沒有冷卻時間的情況下執行連續 API 調用的死循環。

### 2.3 技術與安全風險
*   **接口穩定性:** 提供商保留在不事先通知的情況下更改其 API 結構、請求頭、負載要求或阻止傳入 IP 地址的權利。
*   **身份驗證與安全:** 對於需要憑證或 API 密鑰的接口，您需全權負責保護您的配置安全。OpenStockAPI 不會存儲、傳輸或監控您的私鑰或憑證（所有操作均在本地執行）。

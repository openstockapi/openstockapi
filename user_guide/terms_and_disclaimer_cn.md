## 2. 第三方数据合规性 (服务条款)

数据提供商（包括证券商、基金管理人及数字资产交易所）实施其各自的服务条款 (ToS)。使用 OpenStockAPI 时，您是在间接地与这些接口进行交互，且必须遵守以下规则：

### 2.1 仅限个人及非商业用途
大多数金融数据提供商规定：
*   市场数据、财务报表及公司详情仅供客户/用户个人及非商业用途使用。
*   未经原始数据提供商事先书面同意，严禁向第三方重新打包、商业化或分发此数据。

### 2.2 合理使用与频率限制 (Rate Limiting)
发送过多或过快的请求（抓取/垃圾请求）可能被视为拒绝服务 (DoS) 攻击或资源滥用：
*   **频率限制:** 请尊重 OpenStockAPI 内置的频率限制层，或在您的应用程序中实现自定义请求限制/延迟。
*   **缓存 (Caching):** 主动缓存静态或历史数据（例如公司简介或历史财务报告），而不是重复发送 API 请求。
*   **系统完整性:** 避免在没有冷却时间的情况下执行连续 API 调用的死循环。

### 2.3 技术与安全风险
*   **接口稳定性:** 提供商保留在不事先通知的情况下更改其 API 结构、请求头、负载要求或阻止传入 IP 地址的权利。
*   **身份验证与安全:** 对于需要凭证或 API 密钥的接口，您需全权负责保护您的配置安全。OpenStockAPI 不会存储、传输或监控您的私钥或凭证（所有操作均在本地执行）。
